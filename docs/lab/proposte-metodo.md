# Proposte di modifica al metodo

Gli agenti non toccano le proprie regole (`.github/`, `.claude/`, `scripts/guard/`, METODO,
ESPERIMENTO). Se un giro trova un problema del meccanismo, lo scrive qui. Durante l'esperimento si
correggono solo i bug del meccanismo (`docs/ESPERIMENTO.md`), con una PR umana.
